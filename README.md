# realAndi/logicalrat

Homebrew tap for [LogicalRat](https://github.com/realAndi/LogicalRat) — a macOS menu bar app
for the Logitech PRO X Superlight 2.

```sh
brew tap realAndi/logicalrat
brew install --cask --no-quarantine logicalrat
```

`--no-quarantine` is needed because the build is ad-hoc signed rather than notarized.
